## 2. 레퍼런스 — 2gphone.com (실제 HTML 분석 완료)

앱 주인이 지목한 참고 사이트. **42KB 단일 HTML, 외부 의존은 웹폰트 + GA 뿐.** 우리와 같은 방식이라 그대로 따라할 수 있다.

```
nav (고정)   앵커 3개 + 언어 버튼 5개(KO/EN/JA/ES/FR)
hero         배지 → 한 줄 후킹 → 설명 → CTA 2개 → 앱 스크린샷 1장
#features    6칸 그리드 (제목 + 2줄)
#persona     제품 핵심을 목업으로 시연 (채팅 말풍선)
#download    App Store · Google Play 버튼 2개
footer       이용약관 · 개인정보처리방침 · 계정삭제
```

**훔칠 것 = i18n 구조.** `data-i18n="heroTitle"` 속성 + 파일 안 `const I18N = { ko:{…}, en:{…} }` 객체 + 버튼 스위칭.
파일 하나로 다국어. [`WORLDWIDE_EXECUTION_PLAN.md`](WORLDWIDE_EXECUTION_PLAN.md) Phase G(i18n)를 **앱보다 웹에서 먼저, 공짜로** 검증할 수 있다.

**카피 톤**: 기능이 아니라 감정이 먼저. 히어로가 *"못다한 메세지 전달하기"*, 기능은 그 아래 6칸으로 짧게.

## 4. 조직 하다 진입점 (이 문서의 두 번째 목적)

앱 주인 요구: **"웹에 조직 하다 진입점을 만들어야 한다."**

현재 조직이 "우리도 하다를 열고 싶다"고 말할 창구:

| 경로 | 상태 |
|---|---|
| 광장 탭 무대 섹션 빈 상태 "우리 조직 하다 제안하기" | ✅ 있음 (앱 안, mailto) |
| 프로필 → 설정 → "문의·신고 (운영팀)" | ⚠️ 신고 창구로 읽힘 |
| **웹** | ❌ **없음 ← 이 트랙이 만든다** |

**설계 시 반드시 반영할 것 (앱 정책과 일치해야 함):**
- **셀프서비스 등록은 열지 않는다.** 큐레이션이 사칭 방어선이다 ([`ORG_HADA_PLAN.md`](ORG_HADA_PLAN.md) 결정 ④). 웹은 **제안 폼/메일까지만**, 실제 지정은 운영자 콘솔.
- **조직 전용 계정이 전제다.** `creator_id` 는 이전 불가(0022)라 담당자 개인 계정으로 열면 퇴사 시 하다가 묶인다. `0083` 가드가 이미 **개인 계정의 하다에 org 지정을 거부**한다 → 웹 안내문에 "조직 명의 계정으로 가입해 주세요"가 들어가야 한다.
- 정상 동선: 조직 전용 계정 가입 → 운영자가 「사람 티어 지정」으로 공식 → 그 계정이 「누구나」 하다를 열면 **자동으로 무대**(0080). 하다마다 지정할 필요 없다.
- 수집 항목(현재 앱 mailto 서식): 조직(모임) 이름 · 열고 싶은 하다 · 담당자 연락처.

## 5. ⚠️ 제약 — 레퍼런스처럼 안 되는 것

### ① 다운로드 섹션이 스토어 버튼 2개로 끝나지 않는다
2G PHONE 은 정식 출시라 App Store / Google Play 링크뿐이다. **우리는 아직 베타다:**
- iOS = TestFlight
- Android = **구글 그룹 가입이 선행**되어야 Play 비공개 테스트 링크가 열린다 (메모 `project_android-beta-distribution`)

버튼 2개로 위장하면 "앱 사용 불가"만 보고 이탈한다. [`guide.html`](guide.html) 의 단계 안내를 흡수하되, **정식 출시 때 스토어 버튼 2개로 교체 가능한 구조**로 짤 것.

### ② PC/노트북 설치는 불가능하다 — 정직하게 처리
React Native 네이티브 앱이고 SecureStore·image-picker·notifications 의존이라 웹 빌드가 실질적으로 안 나온다.
**레퍼런스도 iOS/Android 둘뿐이다 = 업계 표준.** PC 방문자에겐 **QR 로 폰에 넘기는 것**이 정답. "PC 설치 가능"으로 쓰면 신뢰만 깎인다.

### ③ 🔴 스크린샷이 저장소에 한 장도 없다 — **유일한 실질 블로커**
`mobile/assets/images/` 엔 아이콘·스플래시뿐, `docs/` 의 PNG 는 전부 기획 목업이다.
레퍼런스의 힘은 히어로의 실제 화면 1장에서 나온다.
→ **실기기 스크린샷 4~6장이 필요하다** (홈 / 챌린지방 인증 / 광장 / 박제). **앱 주인만 만들 수 있다.**
